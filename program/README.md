# program

The program's own `.def` files: the ones saved since they were read, read again. Every so often, with time's `every 5 seconds : read the changed files again`.

```
use program
```

| Words | Does | Example |
|---|---|---|
| `read the changed files again` | Reads the program's .def files saved since they were read again: their definitions, in place of the old ones. Says which; a file with an error keeps its old definitions. To look every so often: time's `every 5 seconds : read the changed files again`. | `read the changed files again` |
