# random

Chance: a random number, a random item.

```
use random
```

`core` uses it, right after `time`. A library used earlier binds looser: on its own, use it in core's order ([core](../core/README.md)).

| Words | Does | Example |
|---|---|---|
| `random number between A0 and A1` | A random whole number from A0 to A1. | `random number between 1 and 6` |
| `random item of A0` | A random item of a list. | `random item of ["rock", "paper", "scissors"]` |
