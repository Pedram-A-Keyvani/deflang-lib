# joined

Text and values written next to each other join into one text: `"x = " 2 + 3` is `x = 5`.

```
use joined
```

`core` uses it, right after `console`. A library used earlier binds looser: on its own, use it in core's order ([core](../core/README.md)).

| Words | Does | Example |
|---|---|---|
| `A0 "A1" A2`<br>`"A0" A1`<br>`A0 "A1"` | Text and values next to each other join into one text. | `"x = " 2` |
